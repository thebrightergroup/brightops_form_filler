# Decision Log

| Field | Value |
|---|---|
| Repo | `[repo-name]` |
| Status | Draft |

## Purpose

This file records material decisions made for this repo.

## Decision log

| Date | Decision | Owner | Status | Link |
|---|---|---|---|---|
| YYYY-MM-DD | `[decision]` | `[owner]` | Draft / Approved / Superseded | `[link]` |

## Decision status values

| Status | Meaning |
|---|---|
| Draft | Proposed or recorded but not yet approved |
| Approved | Approved and current |
| Superseded | Replaced by a later decision |
| Rejected | Considered and not proceeding |

## Notes

Use this file for repo-level decisions. Cross-project decisions should also be recorded in `thebrightergroup/brighter-group-control`.
