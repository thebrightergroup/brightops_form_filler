# Release Checklist

| Field | Value |
|---|---|
| Repo | `[repo-name]` |
| Release name/version | `[release]` |
| Target date | YYYY-MM-DD |
| Release owner | `[name]` |
| Status | Draft / In review / Approved / Released |

## Pre-release checks

- [ ] Scope confirmed
- [ ] Decision log updated
- [ ] Governance status reviewed
- [ ] CAB requirement checked
- [ ] Documentation updated
- [ ] Tests/checks completed
- [ ] Security/privacy impact reviewed
- [ ] Production readiness reviewed
- [ ] Rollback or recovery position documented where relevant

## CAB / approval position

- [ ] No CAB required
- [ ] CAB review completed
- [ ] CAB approval granted
- [ ] Approval conditions documented

## Release evidence

Add links to:

- PRs
- issues
- test evidence
- build notes
- deployment notes
- CAB approval

## Release decision

| Decision | Value |
|---|---|
| Approved for release | Yes / No |
| Approved by | `[name]` |
| Date | YYYY-MM-DD |
| Conditions | `[conditions]` |

## Post-release checks

- [ ] Release completed
- [ ] Known issues documented
- [ ] Follow-up actions created
- [ ] Index/control records updated
